# VidyaSetu

A modern, comprehensive school management ERP and academic learning platform for **Bhaktivedanta Institute Mission Hr. Sec. School (CBSE Affiliated)**.

---

## 🌟 Key Features

- **Classical Ivy League & Vedic Heritage Design**: Built with Playfair Display typography, warm parchment tones, royal navy styling, and custom golden laurel insignia.
- **Admin Management Console**: Student and faculty directories, academic year settings, timetable configuration, exam rosters, and institutional circulars.
- **Teacher Workspace**: Attendance marking, class assignment upload with PDF worksheet attachments, submission review with interactive PDF viewers, and mark entry.
- **Student Portal**: Smart pass card, attendance compliance meter (CBSE 75% cutoff), digital assignment submissions, interactive report cards, and study notes viewer.
- **Study Notes & Chapter Materials**: Class-wise and subject-wise chapter notes repository with interactive PDF document reader, zoom controls, and print/download capabilities.
- **Modern Mobile App Experience**: Custom SVG-contoured navigation bar with smooth scoop notch and floating animated gradient bubble.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Custom Design Tokens
- **Icons & Motion**: Lucide React + Framer Motion
- **Build & Quality**: Oxlint + TypeScript

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
